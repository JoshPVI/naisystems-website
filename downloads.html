Getting started

Installation help

Install the Windows Agent

  1. Download and run Wake-Agent-Setup-0.4.5-win-x64.exe. If updating, first choose Quit from the existing agent’s tray menu.
  2. Confirm installation for your Windows user and choose whether to start at sign-in. No separate .NET installation is needed. The alternative ZIP uses Install-WakeAgent.cmd after extraction.
  3. The optional firewall rule needs administrator approval. It allows the agent on Private/Domain networks and the local subnet. Keep Windows security protections enabled; this beta is unsigned.
  4. Open Wake Agent from Start. One eligible physical private network connects automatically. If a choice is needed, select the correct network on Overview and choose Connect. Use a trusted private network.

Install the Android beta

  1. On your Android phone, choose Download Android beta above and open the APK. Install over the existing Wake app to preserve its data; do not uninstall first.
  2. If prompted, allow installation from the browser used for this download; remove that permission afterwards if you no longer need it.
  3. Open Wake and connect to the same trusted network as your awake PC. No Expo Go or development server is required.
  4. Add a computer manually for basic Wake, or pair the optional Windows Agent to import its MAC address and enable approved controls.

This is a beta APK, distributed outside Google Play. Physical Android pairing, controls and Wake testing are still pending.

Local release-signed build with bundled JavaScript; no Metro or development server needed. Emulator upgrade/launch checks passed. Pixel / Android 17 re-pair and refresh acceptance remains pending. For legacy pairing keys, create a fresh invitation on the PC and pair again.

Install the iPhone beta

  1. On your already-provisioned iPhone, open the iPhone install page above for Wake 1.5.2, build 15.
  2. Use the installation instructions on that finished Expo build page. No App Store listing or public installation is available for this ad-hoc build.
  3. If your iPhone is not provisioned, contact NAI Systems about beta eligibility. Downloading a file does not register a device.
  4. For first-time setup, keep the PC awake and signed in and connect your phone to the same trusted network.

Mobile/device acceptance remains pending. This installation page does not grant public-release clearance or broaden beta eligibility.

Pair your phone with the Windows Agent

Keep the PC awake and signed in, with both devices on the same trusted LAN. In Windows, choose Pair a phone. Review the local controls: all are initially selected for a new invitation, and you can change them before approving the named phone on the PC. Scan the QR or paste the invitation into Wake’s Pair Windows Agent screen and follow the phone’s save/confirmation steps. Existing phone grants remain unchanged; internet consent is separate.

You can switch to Remote Desktop on that phone to approve, then return to Wake within five minutes. If Wake is force-quit or the agent restarts during pairing, create a new invitation.

Use basic Wake without an agent

Enable Wake-on-LAN in the computer’s firmware and network adapter settings. Add its name and the connected, wake-capable adapter’s MAC address in Wake. On Windows, ipconfig /all lists the MAC as Physical Address. The agent does not configure firmware or adapter wake settings for you.

Hardware, power state and network equipment affect waking. A sent packet does not confirm that a computer woke.

Internet wake depends on compatible router/ISP configuration and a working delivery path to the computer. CGNAT, router restrictions or address changes can prevent delivery. Wake does not configure your router; encrypted internet status/history does not itself wake a sleeping PC.

Optional cloud beta and private invitations

Cloud status and history are invitation-only. Request access from NAI Systems; invitation codes are supplied privately. A cloud beta code is separate from the temporary QR invitation used to pair a phone.

If invited, enter your code in Windows Agent Settings → Use invitation, enable sharing on Overview and wait for Cloud status synced. Refresh the paired computer’s Controls once on your home network so the phone receives its own cloud credentials.

After syncing, use Save cloud recovery key and store the file privately somewhere accessible without the PC. Keep codes, pairing invitations and recovery files private. Cloud status does not wake a sleeping PC or deliver power commands; those controls stay local.

Beta limits, updates and removal

The Windows Agent runs in your signed-in session, with no service before login or automatic updates. Closing its window leaves it in the tray; Quit stops it. If the PC address changes, restart on the correct adapter and pair again.

Save your work before testing power actions. Hibernate-to-Wake is unresolved, and Android hardware validation remains pending. Status and history may be delayed; Unknown does not prove that a computer is off.

To remove the agent, revoke phones first if you want to remove their access, quit the tray app, then use Windows Installed apps. Uninstall retains pairing data. Revoking a phone’s cloud access requires a successful sync; if the PC is unavailable, use your saved recovery file through Wake’s recovery help to disable its cloud registration.
